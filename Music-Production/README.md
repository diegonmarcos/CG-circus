# MUSIC PRODUCTION

Master folder for music production tooling and web apps. Scope: digital audio workstations (Music-DAW) and DJ/mixing tools (Music-Mixer). Subfolders hold the existing LMMS and Mixxx reference apps (moved from a-Lfy_CG-Zirkus, #1280).

## FOSS references

- [Ardour](https://github.com/Ardour/ardour): full DAW, GPL-2.0.
- [LMMS](https://github.com/LMMS/lmms): beat/loop DAW, GPL-2.0.
- [Zrythm](https://github.com/zrythm/zrythm): modern DAW, AGPL-3.0.
- [Mixxx](https://github.com/mixxxdj/mixxx): DJ software, GPL-2.0.
- [Carla](https://github.com/falkTX/Carla): plugin host, GPL-2.0.
- [Calf Studio Gear](https://github.com/calf-studio-gear/calf): audio plugins, LGPL-2.1.
- [Tracktion Engine](https://github.com/Tracktion/tracktion_engine): DAW engine library, GPL-3.0 (commercial option).
