# Music -Mixer

Web reference app on the Mixxx DJ mixer (data in src/data/mixxx.json), built by the shared CG engine. Purpose: DJ/mixing notes and tooling. Display name: "Music -Mixer".

## FOSS references

- [Mixxx](https://github.com/mixxxdj/mixxx): DJ software, GPL-2.0.
- [Carla](https://github.com/falkTX/Carla): plugin host, GPL-2.0.
- [Calf Studio Gear](https://github.com/calf-studio-gear/calf): mixing/effects plugins, LGPL-2.1.
- [Ardour](https://github.com/Ardour/ardour): DAW with mixer, GPL-2.0.
- [Zrythm](https://github.com/zrythm/zrythm): DAW with mixer, AGPL-3.0.
