# Music - DAW

Web reference app on the LMMS digital audio workstation (data in src/data/lmms.json), built by the shared CG engine (build.json, ship.yml). Purpose: DAW notes, tooling and experiments. Display name: "Music - DAW".

## FOSS references

- [LMMS](https://github.com/LMMS/lmms): beat/loop DAW, GPL-2.0.
- [Ardour](https://github.com/Ardour/ardour): full DAW, GPL-2.0.
- [Zrythm](https://github.com/zrythm/zrythm): modern DAW, AGPL-3.0.
- [Tracktion Engine](https://github.com/Tracktion/tracktion_engine): DAW engine library, GPL-3.0 (commercial option).
- [DAWproject](https://github.com/bitwig/dawproject): open DAW interchange format, MIT.
- [Carla](https://github.com/falkTX/Carla): plugin host, GPL-2.0.
