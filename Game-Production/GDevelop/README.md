# GDevelop

Folder for GDevelop projects. GDevelop (https://gdevelop.io) is an open-source no-code 2D/3D game engine; core MIT, see the repo for the licence of the editor.

## FOSS references

- [GDevelop](https://github.com/4ian/GDevelop): the engine and editor.
- [GDevelop-examples](https://github.com/GDevelopApp/GDevelop-examples): official example games, MIT.
- [Godot](https://github.com/godotengine/godot): related open engine, MIT.
