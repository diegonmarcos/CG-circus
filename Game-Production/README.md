# GAME PRODUCTION

Master folder for game production. Scope: one folder per engine (Unity, Godot, GDevelop) for projects, notes and tooling. The existing web mini-games stay in c_Circus/games (not engine projects).

## FOSS references

- [Godot](https://github.com/godotengine/godot): game engine, MIT.
- [GDevelop](https://github.com/4ian/GDevelop): no-code game engine, MIT core (editor parts under other terms, see repo).
- [Godot demo projects](https://github.com/godotengine/godot-demo-projects): official samples, MIT.
- [GDevelop examples](https://github.com/GDevelopApp/GDevelop-examples): official samples, MIT.
- [unity-mcp](https://github.com/CoplayDev/unity-mcp): MCP bridge for the Unity editor, MIT.
- [UnityCsReference](https://github.com/Unity-Technologies/UnityCsReference): Unity C# source, reference-only licence.
