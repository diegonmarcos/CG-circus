# Unity

Folder for Unity projects and tooling. Unity (https://unity.com) is a proprietary engine (Unity Personal/Pro/Enterprise terms; some packages and samples are open source). Existing Unity work lives in CG-unity.

## FOSS references

- [unity-mcp](https://github.com/CoplayDev/unity-mcp): MCP bridge for the Unity editor, MIT.
- [UnityCsReference](https://github.com/Unity-Technologies/UnityCsReference): Unity C# source, reference-only licence.
- [NavMeshComponents](https://github.com/Unity-Technologies/NavMeshComponents): navigation components, Unity Companion License.
- [Godot](https://github.com/godotengine/godot): open alternative, MIT.
