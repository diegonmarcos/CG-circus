# Higgsfield

Higgsfield (https://higgsfield.ai) is an AI video generation platform. It is proprietary, hosted and commercial: there is no upstream source repository and no open licence; usage follows its terms of service. This folder holds prompts, workflows and notes for it. FOSS alternatives are listed below.

## FOSS references

- [ComfyUI](https://github.com/comfyanonymous/ComfyUI): node-based generative AI UI, GPL-3.0.
- [Open-Sora](https://github.com/hpcaitech/Open-Sora): open video generation, Apache-2.0.
- [LTX-Video](https://github.com/Lightricks/LTX-Video): open video model, Apache-2.0.
- [Wan2.1](https://github.com/Wan-Video/Wan2.1): open video model, Apache-2.0.
- [Kdenlive](https://github.com/kdenlive/kdenlive): video editor, GPL-3.0.
- [Shotcut](https://github.com/mltframework/shotcut): video editor, GPL-3.0.
